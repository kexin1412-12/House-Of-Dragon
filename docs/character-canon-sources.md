# Character Canon Sources

Use the official HBO House of the Dragon interactive guide as the first
reference when building or reviewing the character library:

```text
https://hotd-interactive-map.micro.hbo.com/
```

This source is useful for:

- official English character names
- titles and court roles
- house, family, faction, and allegiance grouping
- map/place context
- dragon names and dragon/rider context

Use the Warner Bros. Discovery Pressroom image library as the official stills
reference for visual checks:

```text
https://press.wbd.com/na/property/house-dragon/images
```

This source is useful for:

- official episode stills by season and episode
- cast/person labels attached to official stills
- visual reference for costumes, hair, lighting, and scene composition

The public page exposes still metadata and thumbnails, but original or batch
downloads may require a WBD Pressroom login. Do not treat inaccessible press
downloads as script-fetchable assets unless credentials are available.

Local Season 3 reference pulls live under:

```text
references/wbd-hotd-s3-stills/
```

If the HBO guide conflicts with fan-maintained lore sources, prefer HBO for the
runtime character library fields that are shown to viewers, especially
`canonical_name`, `state_timeline[].title_en`, `house`, faction tags, and dragon
entries. Keep episode-specific state changes spoiler-safe by applying the normal
`from` / `to` cursor rules.
